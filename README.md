# Projeto Produtos Flask

Este é um projeto simples de gerenciamento de produtos usando **Flask** e **SQLite**.

## Funcionalidades

- Criar produtos
- Listar produtos
- Excluir produtos
- Interface web com HTML, CSS e JS

## Tecnologias

- Python 3.14
- Flask
- Flask SQLAlchemy
- SQLite
- HTML, CSS, JavaScript
